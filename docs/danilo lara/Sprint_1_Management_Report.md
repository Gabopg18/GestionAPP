## 2. Informe de Eliminación de Bloqueos (Impediments Log)

Se resolvieron los siguientes impedimentos críticos para mantener la velocidad del equipo:
1.  **Falta de Dependencias:** Problemas con la instalación de `psycopg2`. Resolución: Se cambió a `psycopg2-binary` y se estandarizó en `requirements.txt`.
2.  **Problemas de Importación:** Conflictos con el linter del IDE que marcaba errores inexistentes. Resolución: Se realizaron auditorías manuales y se confirmó que el servidor `runserver` operaba sin fallos.
3.  **Coordinación de Base de Datos:** Retraso en la migración a Postgres. Resolución: Danilo coordinó una sesión técnica para automatizar el script de migración.
